- The .NET client queries models, runs their document queries and renders their documents and views. `Model.QueryAsync` evaluates a SysML v2 API & Services `Query` (its scope, the properties it selects, and a `QueryConstraint` comparing a property with `Equal`, `Greater` or `Less`, inverted or combined by `And` and `Or`), and `Model.QueryOslcAsync` OSLC Query text, each answering a `QueryResult` of elements with their id, type and selected properties; a constraint without its operator, operands or constraints cannot be built, and the two forms are never sent together. `Model.RunDocumentQueryAsync` runs a document query the model declares with `DocumentBinding`s of elements by qualified name (`DocumentValue.ElementRef`), objects the service holds by path or id (`DocumentValue.ObjectRef`), strings, numbers, booleans and quantities, answering a `DocumentQueryResult` of columns and rows whose values read every arm, the verdict, state and event rows included. `Model.RenderDocumentAsync` renders a declared document to Markdown or HTML, with the file a rendered set writes it to. `Model.RenderViewAsync` renders a declared view or pseudo-view under `RenderViewOptions` (ports, optional notation, depth) to a `RenderedView` of nested nodes with ports, edges with routes, a table's columns and rows, notes, notices and the notation shown, keeping a geometry, style, canvas or origin the view does not state absent rather than zero. A document query or document the model declares wrongly raises `QueryException`, a `ModelException` keeping the service's status, and a missing model is told apart from a missing declaration. The conformance runner covers Query, RunDocumentQuery, RenderDocument and RenderView.
